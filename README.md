# Word count

Shows word and character counts for the current note, and inserts today's date.

A plugin for [Flint](https://github.com/cucsijuan/flint). Install it from Settings → Plugins → Browse community plugins, or copy `main.js`, `manifest.json` and `styles.css` into your vault's `.flint/plugins/word-count/` folder.
